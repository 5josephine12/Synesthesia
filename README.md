# Aura

A local synesthesia instrument built with vinext, React, Tone.js, and Canvas 2D.

## Requirements

- Node.js `>=22.13.0`

## Run Locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Verify

```bash
npm run lint
npm test
```

This project is intentionally configured for localhost development only. It has no Sites hosting manifest, publishing plugin, or sign-in flow.
